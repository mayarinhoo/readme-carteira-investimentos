# readme-carteira-investimentos
## Carteira de Investimentos

# Descrição do projeto

O projeto Carteira de Investimentos consiste em um sistema desenvolvido em linguagem C que permite ao usuário cadastrar e gerenciar ativos financeiros, acompanhar o valor total de sua carteira e consultar a rentabilidade dos investimentos.

O sistema funciona por meio de um menu interativo no terminal, oferecendo funcionalidades simples para facilitar o controle dos investimentos cadastrados.

# Público-alvo
O sistema é destinado a pessoas que desejam organizar e acompanhar seus investimentos financeiros de maneira simples e prática, especialmente iniciantes que buscam controlar seus ativos. O objetivo do projeto é desenvolver uma aplicação que permita gerenciar uma carteira de investimentos, proporcionando ao usuário uma maneira prática de registrar ativos financeiros, consultar seus valores e acompanhar sua valorização ou desvalorização.

# Funcionalidades do sistema
1. Cadastrar Ativo

Permite cadastrar um novo ativo financeiro. Ao selecionar a opção 1 no menu, o sistema solicita as seguintes informações:

Nome do ativo;
Categoria;
Quantidade;
Preço de compra;
Preço atual.

Após o preenchimento dos dados, o sistema informa que o ativo foi cadastrado com sucesso.

2. Listar Ativos

Permite visualizar todos os ativos cadastrados na carteira.

Caso não exista nenhum ativo registrado, o sistema informa ao usuário que é necessário realizar um cadastro primeiro.

3. Consultar Valor Total da Carteira

Calcula e exibe o valor total da carteira de investimentos, considerando a quantidade e o preço atual de cada ativo cadastrado.

Caso não existam ativos cadastrados, o sistema apresenta uma mensagem informativa.

4. Consultar Rentabilidade Geral

Calcula e apresenta a rentabilidade dos investimentos cadastrados, considerando a diferença entre o preço atual e o preço de compra dos ativos.

O resultado é exibido em porcentagem, indicando se houve valorização ou desvalorização dos investimentos.

Caso não existam ativos cadastrados, o sistema informa ao usuário que é necessário cadastrar um ativo primeiro.

5. Sair

Encerra a execução do programa, finalizando o sistema.

# Instruções para execução

Para executar o sistema, siga as instruções abaixo:

Abra o ambiente de desenvolvimento Dev-C++ 5.11.
Abra o projeto por meio do arquivo .dev.
Verifique se os seguintes arquivos estão incluídos no projeto:
main.c
funcoes.c
funcoes.h
Compile o projeto para verificar se existem erros no código.
Execute o programa utilizando a opção Executar ou o atalho F10, conforme a configuração do Dev-C++.
Após a abertura do terminal, o menu principal será exibido.
Digite o número correspondente à funcionalidade desejada e pressione Enter.
Como Utilizar

Após iniciar o programa, o usuário terá acesso a um menu interativo com cinco opções:

Opção	Funcionalidade

1	Cadastrar Ativo

2	Listar Ativos

3	Valor Total da Carteira

4	Rentabilidade Geral

5	Sair

Basta selecionar a opção desejada e seguir as instruções apresentadas pelo sistema.
